{{if .SharedApp}}Only if the shared Delistd app doesn't work for you.{{else}}Microsoft only allows sign-in through a registered app. It's free and takes about 5 minutes.{{end}}

  1. Open entra.microsoft.com → App registrations → New registration, signed in with your Microsoft account. Microsoft refuses this for some personal accounts (a free Azure account or Microsoft 365 Developer Program tenant gets around it); the full guide explains.
  2. Name it anything. Supported account types: Personal Microsoft accounts only. Leave the redirect URI empty. Register.
  3. Authentication → Advanced settings → Allow public client flows: Yes → Save.
  4. If signing in later says the app lacks permission, add IMAP.AccessAsUser.All, SMTP.Send and offline_access under API permissions.
  5. Copy the Application (client) ID from Overview into the box below.

Full guide: docs/outlook.md. New and not yet confirmed by users; tell us how it goes in #293.
